# FGHOST – All-in-One Penetration Testing & OSINT Framework

**FGHOST** is a comprehensive, modular tool designed for cybersecurity professionals and ethical hackers. It bundles over **15 DDoS/DoS attack methods**, **50+ OSINT modules**, and **40+ utility functions** into a single, easy‑to‑use interface.

---

## What FGHOST Can Do

- **DDoS / DoS Attacks** – TCP SYN, UDP, ICMP, HTTP, Slowloris, NTP/DNS amplification, SIP flood, SSDP amplification, and more.
- **OSINT Toolkit** – WHOIS, DNS enumeration, reverse IP, subdomain brute‑force, port scanning, email/phone lookups, MAC vendor, ASN, IP geolocation, SSL info, GitHub/Reddit user data, and 40+ other public‑data modules.
- **Link Spoofer** – Shorten and obfuscate URLs.
- **Banner Generator** – Create ASCII art and custom banners.
- **Utilities** – Password generator, hashing, encoding (Base64, Hex, ROT13), XOR/AES encryption, port scanner, ping sweep, traceroute, QR code generator, image steganography, and more.

All features are wrapped in a clean, **red‑themed** menu with JSON‑style navigation.
